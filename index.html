中央監視オペレーター 業務マニュアル

1｜基本業務

中央監視オペレーターは、 電力・通信・給水などの都市インフラを監視し、 異常を整理・記録・報告します。

2｜通常監視

  • NORMAL → 継続監視
  • WARNING → 数値・時刻・施設を確認して記録
  • ALERT → 関連施設・履歴を確認して報告準備

3｜警報発生時

  1. 異常を確認する
  2. 数値と基準値を確認する
  3. 関連施設を確認する
  4. 履歴を確認する
  5. 紙に記録する
  6. 状況を判断する
  7. 必要に応じて報告する

4｜判断基準

  • 1施設・1回のWARNING → 記録して継続監視
  • 同一施設で繰り返す → 履歴を確認
  • 複数施設が同時刻 → 施設間を比較
  • 同一インフラで複数施設 → 系統全体を確認
  • 複数インフラで異常 → 共通する要因を考える

5｜重要事項

  • 1つの異常だけで重大と判断しない
  • 小さなWARNINGも記録する
  • 発生時刻を必ず比較する
  • 関連施設を確認する
  • 原因不明の状態では復旧しない

6｜緊急時の流れ

確認 → 比較 → 分析 → 報告 → 復旧
